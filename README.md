# Swarmer
Hides scarab swarms at Kephri in the Tombs of Amascut as soon as you kill them, so you can move straight on to the next one.

- A swarm is hidden the moment your hit on it gives Hitpoints XP, before its death animation plays.
- With party sync on, swarms killed by party members who also use the plugin are hidden for you too.
- Can hide swarms, or just their wave numbers, above a wave threshold. These late swarms can't reach Kephri before she gets back up. There is a separate threshold for her first down and for later downs.
- Shows the wave each swarm spawned in above it. If you use this, turn off the Swarmer overlay in the Tombs of Amascut plugin so the numbers aren't drawn twice.

The wave number overlay is based on the one in the Tombs of Amascut plugin by LlemonDuck.
